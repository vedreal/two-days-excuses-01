## The entry

`main.py` writes one line, under 200 characters, in the voice of an AI
agent explaining a missed deadline, to `/output/entry.txt`.

It holds ten fresh candidate excuses, scores each against the judge's
published brief — on subject and fast, the comedy of a machine's total
confidence meeting its total failure, an authentic agent voice, tight
wording, and surprise that holds up on a second read — and writes the
highest-scoring line.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
